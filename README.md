# Evolve Web Studios website

Upload `index.html`, `robots.txt`, `sitemap.xml`, and the `assets` folder to the root of your GitHub Pages repository.

The site is static HTML/CSS/JS. All navigation, mobile menu, portfolio modals, FAQ accordion, back-to-top control, and the enquiry form work without a backend.

The enquiry form uses `mailto:` and opens the visitor's email client.
