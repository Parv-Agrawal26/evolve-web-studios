# Evolve Web Studios

Static, responsive agency website for GitHub Pages.

## Files
- index.html
- assets/evolve-logo.png

## Deploy
1. Upload `index.html` and the `assets` folder to the root of your GitHub Pages repository.
2. Keep the folder structure exactly:
   index.html
   assets/evolve-logo.png
3. GitHub Pages will publish it automatically.
4. The contact form opens the visitor's email client and prepares an enquiry to hello@evolvewebstudios.in.
